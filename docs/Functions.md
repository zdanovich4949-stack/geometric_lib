## **Circle** :white_circle:

В файле [circle](../circle.py) реализованы сделующие функции:

### area(r)
Возвращает площадь круга по заданному радиусу.

**Параметры:**
* r - радиус круга.

**Возвращаемое значение:**
* math.pi * r * r - площадь круга.

**Пример:**

```python
from circle import area
print(area(228)) // 163 229,76
````

### perimeter(r)

Возвращает периметр круга по заданному радиусу.

**Параметры:**
* r - радиус круга.

**Возвращаемое значение:**
* 2 * math.pi * r - периметер круга.

**Пример:**
```python
from circle import perimeter
print(perimeter(322)) // 2 022,16
```

## **Rectangle** :straight_ruler:
В файле [rectangle](../rectangle.py) рефлизованы следующие функции:

### area(r)
Возвращает площадь прямоугольника по заданным параметрам.

**Параметры:**
* a - длина прямоугольника.
* b - ширина прямоугольника.

**Возващаемое значение:**

* a * b - площадь прямоугольника.

**Пример:**
```python
from rectungle import area
print(area(111,7)) // 777
```

### perimeter(r)
Возвращает периметр прямоугольника по заданным параметрам.

**Параметры:**
* a - длина прямоугольника.
* b - ширина прямоугольника.

**Возвращаемое занчение:**
* 2 * (a + b) - периметр прямоугольника.

**Пример:**
```python
from rectangle import perimeter
print(perimeter(5,10)) // 30
```

## **Triangle** :triangular_ruler:
В файле [triangle](../triangle.py) рефлизованы следующие функции.

## area(r)
Возвращает площадь треугольника по заданным параметрам.
**Параметры:**
* a - длина стороны треугольника.
* h - длина выосоты проведённой на заданную сторону.

**Возвращаемое занчение:**
* a * h / 2 - площадь треугольника.

**Пример:**
```python
from triangle import area
print(area(4,2)) // 4
```
## perimeter(r)
Возвращает периметр треугольника по заданным параметрам.
**Параметры:**
* a - первая сторона треугольника.
* b - вторая сторона треугольника.
* c - третья сторона треугольника.

**Возвращаемое значение:**
* a + b + c - периметр треугольника.

**Пример:**
```python
from triangle import perimeter
print(perimeter(5,11,23)) // 39
```
