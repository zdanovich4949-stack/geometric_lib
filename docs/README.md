# Geometric Library


Библиотека для вычисления площади и периметра геомерических фигур.

**Geometric Library содержит файлы для вычисления метрик следующих геометрических фигур:**


* circle.py - Вычисление площади и переиметра круга.
* reclangle.py - Вычисление площади и переиметра прямоугольника.
* square.py - Вычисление площади и переиметра квадрата.
* triangle.py - Вычисление площади и переиметра треугольника.


## Math formulas
### Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

### Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
